# Computación Paralela

Repositorio para los ejercicios de la materia Computación Paralela.

## Estructura del repositorio

- `ejercicio_0`: Práctica de configuración básica del entorno.
-   - `pcdp`: Práctica de programación en paralelo.
- `ejercicio_1`: Práctica de suma de recíprocos.
- `ejercicio_2`: Práctica de análisis de estudiantes.
